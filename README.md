# Sistema bancario sencillo

## Integrante

- Dayan Reyes Sánchez — Matrícula: 2026-1515

## Descripción

Este es un programa de consola en C# que simula las operaciones
básicas de una cuenta bancaria.

El sistema permite consultar el saldo, depositar dinero, retirar dinero
y mostrar los datos de la cuenta.

El saldo inicial es de RD$1,000. Los datos se mantienen mientras el
programa está en ejecución.

## Requisitos

- .NET SDK instalado.

## Cómo ejecutar

1. Abrir una terminal en la carpeta del proyecto.
2. Ejecutar el siguiente comando:

   dotnet run

3. Escribir el nombre del titular y seleccionar una opción del menú.
